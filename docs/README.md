# Documentation

Our documentation section is split into three parts:

- [User \& Developer Documentation](./book) - This is our published user and developer documentation and is made into a
  published website via `mdbook`. The published version can be found [here](https://cluster-api-gcp.sigs.k8s.io).
- [Proposals](./proposals) - These are proposals for designs or changes to CAPG that require more thought and 
  discussion than a single PR, as well as an archive of proposals that have been completed or closed.
- [Runbooks](./runbooks) - These contain runbooks for maintainer procedures such as version bumps or releasing new 
  CAPG versions.
