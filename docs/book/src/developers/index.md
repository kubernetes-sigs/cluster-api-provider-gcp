# Developing CAPG

Everything you need to know about contributing to CAPG.

If you are new to the project and want to help but don't know where to start, you can refer to our
[Contributing Guide](./contributing.md). This provider is modelled after the upstream Cluster API project. To get
familiar with Cluster API resources, concepts and conventions
([such as CAPI and CAPG](https://cluster-api.sigs.k8s.io/reference/glossary.html#c)), refer to the
[Cluster API Book](https://cluster-api.sigs.k8s.io/).

Are you new with no local setup? Follow our [Prerequisites](./prerequisites.md) guide and then our [Setup Tutorial](./setup-tutorial.md).

Need help running and debugging CAPG locally? Look at our [Running CAPG Locally](./running-locally.md) guide.

Want to understand how the repo, and its CI checks work and fit together? Head to our [Repository Orientation](./orientation.md).

Do you need help with our end-to-end tests? We have our [E2E Test](./e2e.md) pages.

Want to pull nightly images so you can test the very latest code? Follow the guide in our [Nightly Builds](./nightly-builds.md) page.
